5. **Porkbun Support**: Porkbun **requires** the language tag to be specified before checking IDN availability. It supports Japanese IDNs with the `ja` tag [Porkbun KB](https://kb.porkbun.com/article/210-what-are-idn-domains-and-how-do-i-register-them).
