## Repository map

This is a mixed archive and tools repository rather than one active project. The top-level folders currently include:

- `inbox/` — project and conversation handoffs, notes, and archived material.
- `intake/` — captured intake and continuation notes.
- `native-circle/` — Circle-related material.
- `talks/` — speaker portfolio material.
- `transport-tests/` — transport contract, checklist, and regression-test files.
- `video-descriptions/` — scripts and templates for producing model-readable video descriptions.

This map describes folder names and checked-in structure; it does not certify every archived file's accuracy, status, attribution, or suitability for wider circulation. Historical files were left in place.
